## Olá, eu sou o Vinícius 👋

Desenvolvedor **Full-Stack Sênior** especializado em construir back-ends robustos, aplicações web e integrações confiáveis. Trabalho principalmente com **PHP/Laravel** e **Vue.js**, transformando requisitos complexos em soluções simples, sustentáveis e preparadas para produção.

Meu foco está onde engenharia e negócio se encontram: **arquitetura pragmática, APIs bem desenhadas, performance, qualidade de código e entregas contínuas**.

## O que eu faço

- Desenvolvimento de aplicações web e serviços com **PHP, Laravel, Node.js e TypeScript**
- Criação e integração de APIs **REST e SOAP**
- Interfaces modernas e responsivas com **Vue.js, React e Tailwind CSS**
- Modelagem e otimização de dados com **MySQL, PostgreSQL, MongoDB e Redis**
- Ambientes de produção com **Docker, Nginx e Linux**
- Evolução de sistemas críticos com foco em **disponibilidade, performance e manutenibilidade**
